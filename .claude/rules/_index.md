# Rules Index

Reference layer — load on demand, not every session. Project CLAUDE.md points here.

## Always loaded (small, hot rules)

- `skill-activation.md` — Gate: activate skills/agents before freehanding. Load `corrections.md` after activation.
- `mcp-integrations.md` — MCP server catalog (real data sources). Routes to `.claude/skills/integrations/_registry.md`.
- `routing-overrides.md` — manual disambiguation overrides for routing-table.md.
- `routing-table.md` — auto-generated keyword→skill map (regenerated by SessionStart hook). NOTE: distinct from the hand-curated `docs/system-rules/details/routing-table.md` — same filename, different role. THIS one is the auto-generated keyword index; THAT one is the curated agent/skill picker (primary for "which agent/skill for this task?").

## Load recipes

- **"Which command runs X?"** → `docs/system-rules/details/commands.md`
- **"Which agent/skill for this task?"** → `docs/system-rules/details/routing-table.md` (primary) + `docs/system-rules/details/skills-catalog.md` (if still ambiguous)
- **"Which copy skill / command for X?"** → `docs/copy-routing-map.md` (single canonical owner per deliverable + hook/email disambiguation; machine-side precedence in `routing-overrides.md`)
- **"How does the skill system work?"** → `docs/system-rules/details/skills-catalog.md`
- **"What MCP servers exist?"** → `mcp-integrations.md`
- **Quick routing cheat sheet** (no file reads needed):
  - Ads pipeline → `/ads:*` (see commands.md §Ads)
  - CRO → `/cro:page|form|popup|signup|onboarding|paywall`
  - Content → `/content:*` (deprecated → use `/copy:*`; EXCEPT `/content:email` which is still the live email engine)
  - Copy → `/copy:sales-letter|landing` + `/ads:headlines` (full map: `docs/copy-routing-map.md`)
  - Research → `/research:deep|market|persona|trend`
  - Ops → `/ops:daily|weekly|monthly|claude-md`
  - Onboarding → `/project:new` or `/project:profile`

## Extending

- Add a new rule file → put in `docs/system-rules/` (NOT `.claude/rules/` — that auto-loads). Register its trigger in this index.
- Add a new learning → put in `learnings/`. Register here if it should be loadable on-demand.
- Add a new skill/agent → update `docs/system-rules/details/routing-table.md` AND `docs/system-rules/details/skills-catalog.md` (they serve different lookups).
- **Never inline catalog contents into CLAUDE.md** — the whole point is to keep CLAUDE.md under ~80 lines.
- **Net-zero growth:** any new line auto-loaded into CLAUDE.md requires deleting an equivalent line elsewhere.
