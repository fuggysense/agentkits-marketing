# Gut-Wrenching FORMAT — ad-creative image standard

> Reusable creative-direction standard for generating **ad-image prompt SETS** (DCT variants, static ads) for ANY client on this pipeline. Apply after an angle + headlines are approved, when drafting the image prompts. Client-agnostic — always reconcile against the active client's brand kill-list.

## The 9 rules (every prompt set must satisfy)

1. Each image is **completely unique** from the others — no repeated composition.
2. **Different formats and styles** across the set (e.g. documentary photo / split-screen comparison / mock-document or quote-card). Don't ship three of the same look.
3. Any person in the ad must match the **target market's ethnicity/locale** (for SG clients: Singaporean; respect the avatar's audience-scope rule in the client `avatars/_index.md`).
4. Match the **product/industry context** (e.g. property, SaaS, physiotherapy).
5. People must look **real, not AI** — candid, imperfect framing, natural skin texture (pores, asymmetry), authentic local interior/exterior detail; explicitly block glossy stock-photo / plastic-skin / over-symmetry.
6. The **headline must be clear on the ad** (baked into the image, legible) unless the client's flow sets text in Canva — then render a clean text-free plate and note it.
7. **If needed, add a bridge line** or extra on-image info to sharpen clarity for the persona.
8. **Stay away from generic images** — they must POP on the feed.
9. On-image info must be **factually correct and make sense to the persona** — zero confusion, no garbled numbers.

## The bar

Not a generic ad. Every image must be **scroll-stopping, gut-punching, emotion-provoking, curiosity-driving, high-converting** — so good the persona feels physically ill if they scroll past it.

## Applying it (process)

1. Take the approved angle + top-3 headlines (one headline → one image variant is the usual mapping).
2. Assign each variant a **distinct format** (rule 2).
3. Identify the **gut-punch source** — recognition, fear-of-regret, radical honesty, loss, status threat — and make sure it's NOT hype if the client kills hype.
4. Write each prompt with: exact on-image text (headline + optional bridge), real-not-AI casting + texture direction (rule 5), composition, lighting, aspect ratio, and negative prompts.
5. Run through the **Prompt Review Gate (HITL)** before any spend.
6. For multi-image sets featuring the same person/family, **lock a face/character reference** so they stay consistent across variants (see SKILL.md character-likeness block).

## Hard override

Always reconcile against the client's brand kill-list before finalising. The gut-punch must come from emotion the brand *permits*. Example — NeezaNizam kills smiles / upbeat-celebratory tone / "investment"/"dream home"/"break-the-bank" language, so its gut-punch must be recognition / fear-of-regret / radical honesty, never hype.

## Text-legibility caveat (Nano Banana 2)

NB2 can garble small text and numbers. Keep on-image copy short and clean. If a text-heavy variant (e.g. a comparison card with figures) renders messy, generate a clean text-free plate and set the copy in Canva instead.
