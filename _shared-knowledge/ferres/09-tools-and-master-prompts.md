## C. Master prompt catalog — research layer (text/18_63579552_The_AI_Ads_Lab_Master_Prompt_List.txt unless noted)
1. **Deep Research 1 — ICP Deep Dive.** In: client's winning-ad transcript, landing page, VSL. Does: derives the client's ASSUMED avatar from their materials, then mines Reddit/FB groups/IG comments/Amazon/Trustpilot/YouTube/forums/Quora/Twitter for what customers ACTUALLY say. Out: 10-section avatar — demographics, psychographics, daily life, pains (surface + deep), goals, ≥20 verbatim language patterns, objections in their words, decision triggers, and a **gap analysis (customer says vs client addresses)** — the gap section is the payload.
2. **Deep Research 2 — Competitor Analysis.** In: competitor sales pages + ad transcripts (recorded as one Loom of multiple Ad Library ads back-to-back at 2× — tell the model to detect ad boundaries; that warning is in the prompt itself, also text/04). Out: 3–5 competitor profiles (audience, pains emphasized vs ignored, triggers, proof, hook styles, USP, complaints), saturation analysis, opportunity matrix, differentiation plays, "competitor phrases vs authentic customer language."
3. **Deep Research 3 — Market Research.** In: client industry + audience. Does: trend/timing sweep across communities, news, podcasts. Out: trending topics, language evolution, pain hierarchy, urgency factors, influencer landscape, seasonality, macro trends, opportunity gaps, timing advantages — feeds "timely" hooks.
   (Earlier, simpler Perplexity versions of all three live in text/04 — keep for the leaner one-shot variants; walkthrough at 04_part-3-how-to-create-winning-ads [00:22:49].)

## D. Catalog — $300/$500 "Beat Your Control" offer (5-prompt chain, one client winning ad in → 3 beat-the-control hooks out)
4. **Winning Hook Generator.** In: winning-ad transcript + 3 research docs + his ads training. Out: 25 hooks (demo cut used 10 — 06_part-5-full-end-to-end-ai-ad-creation-demo [00:25:28]), 5 each across Shock/Controversy, Curiosity Gap, Social Proof, Fear/Urgency, Benefit-with-twist. Hard rules per hook: 1–2 sentences (first 3–8s), stronger pattern interrupt than the control, same audience but DIFFERENT emotional trigger, hits research pains the control misses, native not salesy. Each hook ships with: why it beats the control + which research insight it uses.
5. **Winning Hook Selector.** Scores every hook 1–10 on six axes — scroll-stop power, emotional trigger strength, audience alignment, conversion potential, algorithm/engagement, differentiation — totals /60, picks TOP 2, and forces the two winners onto DIFFERENT psychological triggers (one fear, one curiosity) for testing diversity.
6. **Scene Concept Generator.** In: one winning hook + the research. Out: 5 standalone video concepts, each = title + avatar persona (age/style/one defining feature) + environment + action sequence + exactly how/when the avatar says the hook line + named psychological engine. No avatar/environment/action reuse; ≥2 of 5 avatars must be occupation/lifestyle matches for the audience. Demo note: best concepts here are relatable, not "wild crazy AI dragon shit" (06_part-5-full-end-to-end-ai-ad-creation-demo [00:38:14]).
7. **Scene Concept Selector.** V2V scoring matrix, 1–10 × 6: scroll-stop velocity (first 0.5s), emotional impact, narrative clarity (message readable from visuals alone), shareability, **generation fidelity** (will the model actually render this scene well — swap "Sora 2" for your renderer), conversion potential. Markdown table → highest total wins → data-backed recommendation. (Run at 06_part-5-full-end-to-end-ai-ad-creation-demo [00:38:22].)
8. **Sora Scene Builder.** ⚠️DATED (Sora-specific; pattern ports to Seedance/Veo). Compresses winning concept into a 50–100-word, four-part prompt per OpenAI's guide: prose scene description → cinematography (shot + mood) → numbered action beats → dialogue = the exact hook line. Style rules: directorial tone, "describe, don't command," 100% faithful to the concept. Then paste into renderer; repeat the chain per selected hook (doc says 3 hooks; demo selected 2). (Run at 06_part-5-full-end-to-end-ai-ad-creation-demo [00:45:58].)

## E. Catalog — $3k+/retainer "Andromeda Antidote" offer (full 25-ad volume builds) ⚠️PLATFORM (Meta/Andromeda framing throughout)
9. **Breakthrough Ad Ideas.** In: all 4 docs. Out: 25 scroll-stopping angles — 5 per format: talking head, talking head + AI-avatar stitched hook, full AI, B-roll, testimonial/UGC. Every angle: 3-sec pattern-interrupt hook, addresses researched objections, strong emotion, native feel, drives to [DESIRED ACTION]. Priority rule: majority of angles **capture existing demand** (in-market prospects), don't create it. (Oct 2025 deck version asked for 50 angles → human-selects top 25, 5 per format — text/04.)
10. **Master Viral Ad Script.** In: 4 docs + chosen angles pasted in. Out: 5 scripts, 30–60s, "entertainment first, advertisement second," element order deliberately varied. Required elements woven naturally: hook (exact customer language) → problem agitation (their research words) → solution tease (don't reveal all) → proof stack (specific numbers) → objection handling (top objections from competitor analysis) → urgency tied to EXTERNAL factors → clear CTA. Format: 6–10 scenes of 3–8s, visual description per scene, on-screen text for first 3s, platform slang, Meta-compliant.
11. **Ad Scene Generator** (per-scene, full-length ads). In: one script line/scene. Out: JSON — scene_analysis, video-gen prompt, duration, visual_style, transition_notes. Scene-type visual grammar baked in: problem agitation = darker/frustrated; solution tease = brighter/hopeful; proof = clean/credible; objection handling = reassuring/authority; urgency = dynamic/time-pressure; CTA = clear/direct. Constraints: NO text overlays (add in CapCut), vertical format, compliant. Run once per scene.
Prompt hack: name a dead copywriter in any of the above to set register — Halbert (story), Carlton (aggressive/urgency), Schwartz (sophisticated/high-ticket), Hopkins (proof/B2B), Kennedy (contrarian), Ogilvy (premium) (text/04).

## F. Catalog — statics layer (text/24; full method in 06-statics-playbook.md)
12. **Quick Brief Builder.** Paste any raw offer material → tight labelled one-pager (who it's for, awareness, the pull, what we sell, promise, differentiator, proof, numbers/next step, look & feel); facts only, guesses tagged [GUESS]. Skip if a full intel/avatar pack already exists.
13. **Swipe Teardown + Rebuild** (the 80% path). In: brand docs + one long-running competitor image ad (Foreplay, filter: image/live/30+ days/sort longest-running — ⚠️DATED $59/mo). Three forced passes: WHY IT WINS (eye-path, hook/promise/action, awareness level, named emotional button) → HOW WE REBUILD (keep converting structure+psychology, swap product/offer/voice/colours) → THE PROMPT (one copy-paste NB Pro prompt: format lane, what it must "pass as," scene, top-to-bottom layout + real-product placement, brand colours, framing/lighting, exact on-image words in quotes, 4:5 with centre-safe square crop, `--ar 4:5`) + 2 alternate test headlines.
14. **From-Scratch Concept Engine** (the 20%). In: brand docs + [N] count. Out: N concepts, each exactly FORMAT (product shot / social proof / infographic / native-advertorial / breaking-news) + HOOK (exact on-image words, concrete, feed-glanceable) + PROMPT (paste-ready, 4:5, centre-safe). Must vary angle/emotion/awareness, not just visuals; "twenty more" continues without repeats.
15. **Face-lock composite pattern** (demo prompt worth stealing): when compositing a real person's photo, open with a NON-NEGOTIABLE block demanding pixel-level facial fidelity ("background replacement around an untouched subject"), then OUTPUT/SUBJECT/SCENE/ON-IMAGE TEXT (exact spelling, quoted)/LIGHTING/COLOUR/HARD CONSTRAINTS sections (text/24).

## G. Operating rules across all prompts
- Every generation prompt is research-fed: attach the docs, never run naked (text/18; 06_part-5-full-end-to-end-ai-ad-creation-demo [00:17:18]).
- Generate → score → select is the universal shape: wide batch, numeric rubric, top 1–2 survive, forced diversity among survivors (prompts 5, 7; selection step in text/04).
- You stay the judge: "don't leave your copywriting skills at the door" — override AI selections when taste says so (06_part-5-full-end-to-end-ai-ad-creation-demo [00:34:38]).
- Image→video, not text→video, when a product/person must persist; AI hooks get stitched onto client talking-head ads as a deliverable (06_part-5-full-end-to-end-ai-ad-creation-demo [01:41:16]).
- Compliance guardrails ride inside the prompts: no timeframe claims, no before/afters, imply results instead (text/04; text/24 QA step).
