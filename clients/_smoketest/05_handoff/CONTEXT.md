# 05_handoff — Handoff Contract

Package final deliverables, document how to use them, and capture learnings so the next campaign starts smarter.

## Inputs

- Approved output from `04_review/output/`
- Final creative files from campaigns, videos, or production folders
- Campaign state, metrics, and review notes

## Process

1. Package final deliverables in `output/deliverables/` or the relevant campaign output folder.
2. Write a short handoff note: what was delivered, where it lives, and what it is for.
3. Log reusable learnings in `_brand/learnings.md` or the relevant skill learnings file when approved.
4. Promote approved reusable assets to `_brand/brand-assets/` and update `_brand/asset-map.md`.
5. Leave campaign-specific experiments inside `campaigns/<campaign>/`.

## Output convention

- `output/<YYMMDD>-handoff-note.md`
- `output/<YYMMDD>-asset-promotion-log.md`
- `output/<YYMMDD>-lessons-learned.md`

## Done looks like

The client or future agent can reopen the folder later and understand what shipped, what was approved for reuse, and what should happen next.
