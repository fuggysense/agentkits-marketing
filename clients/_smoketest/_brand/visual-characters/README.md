# Visual Characters

Use this folder only for generated presenters, mascots, recurring faces, actor references, and face-lock assets.

Buyer targeting lives in `_brand/buyer-profile.md` under `## MICRO-PERSONA MAP`.

Do not create visual-character files to define a buyer segment. If a character is based on a buyer micro-persona, link back to the `micro_persona_id` from `_brand/buyer-profile.md`.
