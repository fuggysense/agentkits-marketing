## Saturated category messaging (everyone in the market already runs these)
- "Your dream home is closer than you think." (aspiration / drone-shot lifestyle)
- "Make data-driven property decisions." (dashboard / data-tool positioning — PropData Pro owns it)
- "Trust your agent." (status-quo agent framing)
- Endless listing-feed / "browse more units" messaging (PropertyGuru, 99.co)
- "Free consultation" / "no obligation" (commissioned-agent hook; this buyer knows free isn't free)

## Rejected tactics (this buyer actively bounces off these)
- Fake urgency / "decide tonight, other buyers viewing" — resented as hard-sell theatre.
- "Trust me, I'm experienced" / credentials with no visible work.
- Founder outrage rants attacking commission agents by name (MP-03 rejects this; also violates the CLAUDE.md "contrast the model, not the people" rule).
- Anonymous-crowd / Telegram-group sourcing as a selling point.
- Generic "advisory" framing with no concrete mechanism.

## Hard brand bans (CLAUDE.md constraints — never write)
- Any claim implying Meridian is a licensed CEA estate agent or provides agent representation.
- Any "guaranteed" resale gain / "property always goes up" appreciation promise.
- Hype / "secret" / fear-baiting about the property market.
- Naming or punching down at specific commission agents.
