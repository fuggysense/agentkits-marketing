# _example-campaign — concrete workspace template

This folder is a **read-only example** of the canonical campaign + concept workspace shape. Fresh agents should browse it to understand what files exist at each phase before scaffolding a real campaign.

- All values are `{{placeholders}}` — do NOT copy verbatim into real client work.
- Replace `_example-campaign` with the real `<campaign-slug>` and `_example-concept` with the real `<concept-slug>` when scaffolding via `/campaign:new`.
- Read `../README.md` (campaigns layer rules) and `../../CONTEXT.md` (Entry Protocol) before editing any real campaign workspace.
- Each phase folder under `video-concepts/_example-concept/` has a `README.md` that names: what lives here, which files load it, and the owner agent.
