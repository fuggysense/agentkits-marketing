# 05_handoff — Handoff Contract

Package final deliverables, document how to use them, and capture learnings so the next campaign starts smarter.

## Inputs

- L4 (working): approved output from `04_review/output/`, final creative files from campaigns/videos/production, campaign state, metrics, and review notes.
- L3 (reference): `../_brand/learnings.md` and `../_brand/asset-map.md` (where reusable assets and lessons get promoted).

## Process

1. Package final deliverables in `output/deliverables/` or the relevant campaign output folder.
2. Write a short handoff note: what was delivered, where it lives, and what it is for.
3. Log reusable learnings in `../_brand/learnings.md` or the relevant skill learnings file once approved.
4. Promote approved reusable assets to `../_brand/brand-assets/` and update `../_brand/asset-map.md`.
5. Leave campaign-specific experiments inside `../campaigns/<campaign>/`.

## Outputs

- `output/<YYMMDD>-handoff-note.md`, `output/<YYMMDD>-asset-promotion-log.md`, `output/<YYMMDD>-lessons-learned.md`.
  - Done: the client or a future agent can reopen the folder and understand what shipped, what was approved for reuse, and what should happen next.
