# Product Inputs

Put reusable product source material here before it is distilled into `_brand/offer.md`, `_brand/asset-map.md`, or campaign-specific briefs.

Expected files:

- `product-features.md`
- `claims-and-proof.md`
- `product-faq.md`
- `product-images/`

Product images that become approved reusable assets should be promoted into `_brand/brand-assets/` and logged in `_brand/asset-map.md`.
