**(b) Citation audit is now BLOCKING in hardened mode.**
- `run_hardened_angle_stage()` signature (`~line 933`) — added `citation_blocking: bool = True`.
- Loop body (`~line 967`) — moved `_audit_citations()` to run PRE-bank (right after `compute_gate_verdicts`). When `citation_blocking and unverified`, each unverified PASS angle is demoted: `verdict="FAIL"`, `min_score=0`, `citation_blocked=True`, with a BLOCKING WARN log. Running pre-bank keeps the monotonic invariant intact — a fabricated-evidence angle simply never banks, rather than un-locking an already-banked winner. It then routes to regen via the existing `failed_ids` path.
- Old post-bank advisory call (was `~line 994`) replaced with a comment; the advisory log line is now gated on `not citation_blocking` so it only fires on the soft/advisory path (no double-logging). `citations_unverified` is still recorded in `gate_log`.
- Call site in `main()` (`~line 1375`) — passes `citation_blocking=True` explicitly with an inline comment.

Design note: `_audit_citations` returns `[]` when `buyer_profile_text` is empty, so the two offline unit tests (which pass `buyer_profile_text=""`) are unaffected — citation-blocking is a no-op without a profile, which is also why it cannot fire on the soft path (soft path loads no profile).
