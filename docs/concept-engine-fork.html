The 10 differences (Iman, verbatim-sourced)

Every row was confirmed via direct quote in one of 10 isolated queries to Iman's live Whop chatbot. Source: iman_organic_vs_ads_concepts.md.

Dimension Organic concept Ad concept
Job of asset Discovery + resonance. Make people care. Efficiency + qualification. Make the right people convert.
Brief starts from Creator's worldview, human truth, sharp opinion, pattern interrupt Buyer's pain, desire, mechanism, objection, market angle — a commercial thesis
Awareness target Unaware → problem-aware (sometimes solution-aware) Problem-aware → product-aware (cold). Most-aware = retargeting only.
Specificity Broader umbrella at TOFU so algorithm finds adjacent viewers. Broader, not unfocused. Hyper-specific. One named person, one named pain, one named moment. "Broad TAM is a trap at the ad level."
Pain framing Relatable, identity-based, self-diagnostic. Lead with the tension. Let them self-diagnose. Surgical, painfully specific, cost-of-inaction. Lead with the pain.
Proof load Layered, mid or close. OK to delay. Build trust deeper. Front-loaded. Hook or immediately after. "Colder the audience, earlier the proof."
Volume per concept 5-10 videos per pillar before tapped 3-5 variations per angle. "Not 12. Not 20." Vary hook, keep promise.
CTA influence Looser. Soft CTAs default (follow / save / DM keyword). Tight. Hard CTA back-propagates into sharper promise, qualified pain, relevant proof.
Risk tolerance Smaller, measured. Going hard too fast distorts brand. Bigger creative swing — inside a tight commercial frame. Not "be edgy"; "find resonance faster."
Position in loop Lab. Discover signal cheaply. Scaler. Proven signal gets budget. Winners recycle back into organic.

Cross-surface rule (applies to both):

  1. Rule 0: Capture CTA destination FIRST. CTA back-propagates upstream into the brief.
  2. Rule 4: Repurposing is asymmetric — organic discovers → paid validates → organic resharpens. Never port raw organic to paid untouched; keep the angle/pain/transformation, rewrite hook/CTA/pacing.
  3. Rule 5: Concept ≠ hook. Brief the concept fully before writing any hook.
  4. Rule 6: Polarizing ≠ lying. At $5K-$15K+, exaggeration kills lead quality. Buyers are buying trust + certainty.

The two brief templates (locked in the prompts)

/content:concepts — 7 fields per concept

  1. WHO — persona slice (broader than paid)
  2. TENSION — the felt-but-unspoken thing (not raw pain)
  3. BELIEF — the assumption flipped
  4. STORY / INSIGHT — creator's lens / lived experience / observation
  5. PROOF — layered, can be delayed
  6. PILLAR + FUNNEL STAGE — Edu/Sell/Story/Inspire + TOFU/MOFU/BOFU
  7. CTA ALIGNMENT — soft action (save / follow / DM)

Key rule: tension ≠ pain. Tension = felt-but-unspoken. Pain = what they'd name when asked.

/ads:concepts — 8 fields per concept

  1. NAMED PERSON — ONE specific buyer (not a segment)
  2. NAMED PAIN — urgent, time-bound, expensive
  3. NAMED MOMENT — the trigger when pain becomes intolerable
  4. DESIRED OUTCOME — specific state change
  5. MECHANISM TO BELIEVE — unique / named / differentiated
  6. PROOF FRONT-LOADED — first-5-second credibility element
  7. OBJECTION NEUTRALIZED — the ONE objection this defuses
  8. CTA + AWARENESS — hard ask + awareness level

Key rule: if you can't name person+pain+moment in 30 sec, the concept is too broad. Go narrower.

  3. Step 3 · 45 min Build /content:concepts-select + /ads:concepts-select.

    Same playbook as /hooks:select — score against criteria, enforce diversity, output top picks. Selection rules:

    • Organic: pick 3/week. Diversity = different pillars + different beliefs flipped.
    • Paid: pick 2-3/batch. Diversity = different objections neutralized + different mechanisms.

  4. Step 4 · 30 min Add --mode=ads to /hooks:generate.

    Currently /hooks:generate defaults to organic (voice-locked, broader). For ads, the same command needs:

    • Volume: 3-5 hooks per concept (not 20)
    • Pain framing: surgical, not relatable-self-diagnostic
    • Proof: front-loaded in the hook itself
    • Voice fit floor lowered to 7/10 (was 8/10)

  5. Step 5 · later Wire the script stage — /content:script takes a selected hook + the original concept + voice files, produces the full filmed-ready script (hook + body + CTA). Underlying skill: script-skill.
