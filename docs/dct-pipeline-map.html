01In one sentence

What this whole thing is, before the diagrams.

You're moving how each ad test is stored from one big messy file per test (dct-tracker.json) to one clean file per test (dct.json) — so your scripts stop tripping over each other — and then adding a one-command tool (allocate) that files a finished image into the right test safely. I proved the first half works on a safe draft test. The live tests and the automation are still ahead.

06How to use the pipeline (commands)

The actual steps, in order. green = works now, orange = not built / being changed.

1

Inspect a conversion (safe — changes nothing) ✓ works now

Run the converter in look-only mode. It writes a candidate to a scratch path so you can eyeball it before committing.

2

Commit the conversion ✓ works now (10-5-5)

Overwrites the live dct.json, after auto-backing-up and running a lossless audit. Aborts if anything is unaccounted.

3

Render an image from a prompt ✓ works now

Turns a text prompt into a PNG via GPT Image 2 (Azure). The --from-tracker mode is being repointed to read the new dct.json (Path B work).

File the image into a test ✕ not built — Build #10

The image-first move: allocate picks the next free slot, MOVES the render into the test's images/, and updates both ledgers in one safe step. Refuses an 11th image, never discards.

08Plain-English glossary

DCT
One ad test = one audience (avatar) + one offer. Holds the angles, copy, and a pool of images Meta mixes.
dct-tracker.json
The OLD storage file. One big file per test, bundling everything — the thing we're moving away from.
dct.json
The NEW storage file. One clean file per test, holding only that test's facts. The thing we're moving to.
converter / normalizer
The script that turns an old file into a new one without losing anything. Built for 10-5-5; the 3-2-2 one is still to do.
emitter
Whatever creates a brand-new test (the ad-concept-engine behind /ads:concepts). Still writes the old format today.
allocate
The unbuilt one-command tool that files a finished image into the right test, safely (Build #10).
_assets.json
The campaign-wide list of every image and its status (available / allocated / published).
10-5-5 / 3-2-2
Two ad-test recipes. 10-5-5 = 5 angles, 10 mixed images (new). 3-2-2 = 3 angles, 2 copies + 2 headlines each (older, your live ones).
