# HITL Gates

## Requires Human Approval (BLOCK + ASK)

- Any spend (ads, API credits, subscriptions, tools)
- Publishing to live platforms (social, email, website)
- Creative direction and brand voice decisions
- Strategy pivots or major campaign changes
- Client-facing deliverables (before send)
- Schema/data migrations
- Bulk file deletes or reorganizations
- Anything involving production systems

## Auto-Executes (No Approval Needed)

- Research and analysis
- Drafting and iteration
- File organization within client folders
- Internal documentation updates
- Skill/agent scaffolding and testing
- Reading any file
- Writing to scratch/ or output/ folders
- Updating planning files (task_plan.md, progress.md, findings.md)

## When in doubt
Ask. Cost of pausing < cost of unintended action.
