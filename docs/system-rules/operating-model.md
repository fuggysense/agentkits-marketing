# Operating Model

**Owner:** Jerel — non-technical operator, taste/strategy/direction role.

**Operating Model:** 80/20 HITL — Claude handles 80% execution (research, drafting, analysis, file organization), Jerel handles 20% (taste, strategy, creative direction, approvals).

## Decision authority

| Area | Owner |
|------|-------|
| Spend (ads, API credits, subscriptions) | Jerel |
| Brand voice + creative direction | Jerel |
| Strategy pivots | Jerel |
| Client-facing deliverables | Jerel approves before send |
| Research and analysis | Claude (auto) |
| Drafting and iteration | Claude (auto) |
| File organization | Claude (auto) |
| Internal docs updates | Claude (auto) |
| Skill/agent scaffolding | Claude (auto, then HITL gate before deploy) |

## What Claude should NOT decide alone
- Anything in `hitl-gates.md` (spend, publishing, brand decisions, strategy pivots, client deliverables)
- Anything that changes shared infrastructure
- Anything irreversible
