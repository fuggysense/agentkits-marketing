How this admin works

This page is a viewer + command generator — it reads /admin/manifest.json (refreshed every time you run sync.sh) and shows current state. For any change, fill the form and copy the generated CLI command into your terminal.

Why? here.now's API doesn't send CORS headers, so the browser can't call it directly. CLI commands (running on your Mac) work fine — and your API key never leaves ~/.herenow/credentials.
