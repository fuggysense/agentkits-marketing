# Video Brief Template — Phase 2b Output

> Used when a DCT batch's `format ∈ {UGC, Founder Video, UGC Testimonial, Demo, VSL}`. Each video creative gets ONE filled-in brief. The brief is what a UGC creator, founder, editor, or video director executes — without further questions.

A brief is NOT a script. A script is the words. A brief is the entire production direction.

---

## Brief Structure

```markdown
## Video Brief: [Batch Name]
**Format:** [UGC / Founder Video / UGC Testimonial / Demo / VSL]
**Avatar target:** [Avatar N: Name]
**Angle:** [Angle title]
**Sophistication:** L[1-5]

---

### 1. Creative Vision

**Tone:** [authentic / energetic / confessional / clinical / peer-to-peer / etc.]
**Visual aesthetic:** [UGC raw / cinematic / meme / WhatsApp screenshot / studio-polished / handheld documentary / etc.]
**Target emotion:** [identification / relief / curiosity / urgency / quiet recognition / etc.]
**Reference videos** (links if available): [URL or description of 2-3 viral references in this aesthetic]

One paragraph that a creative director or UGC creator can read and immediately know what they're making.

---

### 2. Scene Breakdown (6 scenes for short-form ≤30s; act-based for VSL ≥2min)

#### Short-form template (UGC / Founder Video / UGC Testimonial / Demo)

**Scene 1 — Hook (0-3s)**
- **Location:** [exact setting — bedroom / kitchen / car / office / outdoors / etc.]
- **Lighting:** [natural daylight / warm overhead / harsh fluorescent / golden hour / dim lamp / etc.]
- **Props:** [list every visible item — phone, laptop, mug, paperwork, product, etc.]
- **Performer action:** [what they're doing physically — scrolling, looking up, sighing, holding the product, etc.]
- **Copy/VO:** [exact words on-camera or in voice-over]
- **Visual beat:** [what the audience sees — close-up of face, wide shot, cutaway to product, text overlay, etc.]

**Scene 2 — Problem Identification (3-8s)**
[Same structure as Scene 1]

**Scene 3 — Mechanism Reveal (8-15s)**
[Same structure — this is where the unique HOW is shown / explained / demoed]

**Scene 4 — Social Proof (15-18s)**
[Same structure — testimonial cutaway, results screenshot, named-customer quote, etc.]

**Scene 5 — Transformation (18-22s)**
[Same structure — show the after-state, the relief, the result]

**Scene 6 — CTA (22-25s)**
[Same structure — direct CTA frame, button overlay, voice-over close, urgency element]

#### VSL template (≥2min, act-based)

**Act 1 — Hook (0-15s):** Pattern interrupt + premise. State the bold claim or counter-narrative.
**Act 2 — Problem Amplification (15s-1:30):** Make the problem visceral. Use 2-3 micro-stories or stat anchors.
**Act 3 — Mechanism Reveal (1:30-3:30):** Name and explain the unique HOW. This is the longest act.
**Act 4 — Proof + Objection Handling (3:30-6:00):** Stack testimonials, results, demonstrations. Pre-empt the top 3 objections.
**Act 5 — Offer + Urgency (6:00-end):** Stack the offer. Anchor against alternatives. Drive urgency. Close with low-friction CTA.

For each act: copy/VO outline + visual beats per minute + b-roll requirements + on-screen text moments.

---

### 3. Performer Notes

- **Age range:** [e.g. 28-42]
- **Representation:** [ethnicity / gender / accent — match avatar demographics]
- **Personality:** [peer-to-peer / authoritative / confessional / playful / serious]
- **Energy level:** [low and thoughtful / medium and warm / high and animated]
- **Eye contact:** [direct to camera / slightly off-camera / looking away during vulnerable beats]
- **Pacing:** [slow and deliberate / conversational / quick / mixed]
- **Dress code:** [casual at-home / business casual / activewear / industry-specific uniform]
- **Voice direction:** [natural inflection / over-enunciate / quiet whisper / etc.]
- **Do:** [3-5 specific behaviours — "include a real laugh", "let silence sit for 1s after the hook", etc.]
- **Don't:** [3-5 specific behaviours to avoid — "don't smile during the problem section", "don't wear branded items", "don't rehearse the inflection — let it land naturally", etc.]
- **Performer can include:** [optional context — partner present, kids in background, real workspace, etc.]

If Founder Video: founder is the performer; performer notes cover wardrobe / location / preparation level / what NOT to script.

If UGC Testimonial: performer is a real customer (or actor playing one); add interview-question structure + b-roll list + permission/release note.

---

### 4. Audio Specs

- **Music:** [none / lo-fi background / cinematic build / driving beat / specific reference track]
- **Music volume relative to VO:** [music ducks under VO / music at 30% throughout / music only in opening + closing / etc.]
- **Voice-over style:** [natural speech / narrator voice / inner-monologue / multi-speaker / etc.]
- **Silence beats:** [where intentional silence sits — after the hook, before the CTA, etc.]
- **Sound design:** [ambient sound / foley / notification dings / typing / etc.]

---

### 5. Graphics / Overlays

- **Hook text on-screen:**
  - Text: "[exact 2-8 words]"
  - Timing: [appears at 0:01, holds for 2s, fades]
  - Style: [bold sans / handwritten / typed / etc.]
- **Mechanism visuals:**
  - [if explaining a 3-step framework, list what appears on-screen for each step]
- **Proof overlays:**
  - [logos / star ratings / quoted testimonial text / before-after / data visualisation / etc.]
- **CTA frame:**
  - Visual style: [button / text card / on-screen URL / QR code / etc.]
  - Timing: [appears at 0:22, holds to end]
  - Copy: [exact CTA copy]

---

### 6. Technical Specs

- **Duration:** [exact length — 25s / 60s / 3min / etc.]
- **Aspect ratio:** [9:16 (full-screen mobile) / 1:1 (feed) / 4:5 (Reels-friendly) / 16:9 (YouTube)]
- **Resolution:** [1080p minimum / 4K if supplied]
- **Frame rate:** [30fps standard / 60fps if smooth motion / 24fps for cinematic]
- **Captions:** [burned-in / SRT file / both]
- **File format delivery:** [MP4 H.264 / etc.]

---

### 7. Timing Map

The spine the editor cuts to. One row per beat.

| Time | Beat | What Happens | Audio | On-Screen Text |
|---|---|---|---|---|
| 0:00 | Open | [opening shot] | Music starts | — |
| 0:01-0:03 | Hook | [hook beat] | VO start | "[hook text]" appears |
| 0:03-0:08 | Problem | [problem beat] | VO continues | — |
| 0:08-0:15 | Mechanism | [mechanism beat] | VO + sfx | [mechanism graphic] |
| 0:15-0:18 | Proof | [proof beat] | VO | [proof overlay] |
| 0:18-0:22 | Transformation | [transformation beat] | VO + music swell | — |
| 0:22-0:25 | CTA | [CTA beat] | VO close + music | [CTA card] |

```

---

## Quality Bar

A brief passes if:

- [ ] All 6 scenes (or 5 acts for VSL) have location + lighting + props + performer action + copy/VO + visual beat filled
- [ ] Performer notes are specific enough that a casting agency can find the right person without further questions
- [ ] Hook is in the first 3 seconds with a specific on-screen text spec
- [ ] CTA is in the brief with both visual style and exact copy
- [ ] Timing map ties every beat to a second
- [ ] Audio specs are not "TBD" — even "no music" is a decision
- [ ] Performer voice draws on the avatar's Raw Inner Dialogue (avatar §14) where applicable
- [ ] Sophistication-level aesthetic match (L4 raw vs L1-2 polished vs L5 pure UGC)

A brief fails if:

- It reads as one paragraph of "creative direction notes"
- Performer notes are generic ("real person, authentic")
- The 6 scenes are summarised into 2-3 bullet points
- "Music: TBD" or "VO: founder will figure out"
- No timing map
- The brief could be used for any product / any brand / any avatar

## How `ad-concept-engine` populates the brief

1. **Avatar avatar-N.md** provides Performer Notes (demographics + Raw Inner Dialogue § 14 → performer voice)
2. **Angle title + core idea** from `angles/wave-N.md` → Creative Vision
3. **Sophistication level** drives aesthetic + visual style + CTA pressure
4. **Buyer Language Bank §5** + **Golden Nuggets §5.5** provide on-camera copy + VO lines (verbatim where possible)
5. **Proof Inventory §8** drives Scene 4 (which proof to feature)
6. **Messaging Hierarchy §9** drives the 6-scene narrative spine
7. **Format-specific rules** from `paid-advertising` skill drive Technical Specs
