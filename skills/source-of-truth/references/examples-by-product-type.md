# Examples by Product Type — HITL Phase 4 Reference

When drafting Q3 (Priority Angles) and Q2 (Core Message) options for the AskUserQuestion checkpoint, use the patterns below as scaffolding for the relevant `product_type`. These are not literal scripts — they're the SHAPE of how angles, messaging, and proof should differ per product type.

**Critical rule:** load the section that matches `product_type` from the intake JSON. Do NOT mix patterns across product types. A property angle ("The 3-Number Test") doesn't translate to ecom; an ecom angle ("Before/After in 7 days") doesn't translate to SaaS.

---

## Property / Real-Estate (consulting, agent services, property tech)

**Sophistication baseline:** L4 in mature markets (SG, US coastal). 10+ established competitors with similar "asset progression / upgrade" claims.
**Awareness baseline:** Problem-Aware → Solution-Aware. Buyers actively researching for months before booking.

**Core message recommendation:** Option C (mechanism-led) anchored on a named methodology. Generic outcome promises (("upgrade to a condo")) are saturated.

**Drafted angle patterns:**
1. **The N-Number Test** (Problem-Aware) — qualification isn't salary, it's specific math · Static + Carousel + Founder · Risk: requires the actual numbers to be live, not vague
2. **Spouse-Initiator Reframe** (Problem-Aware) — speak to the partner who's already convinced, give them ammunition for the hesitator · UGC + Carousel · Risk: tone must be "same team, different timing"
3. **Bad Agent Experience** (Contrarian) — directly acknowledge prior scar tissue, anti-pattern positioning · Founder + UGC testimonial · Risk: needs SPECIFIC anti-patterns named, not vague "we're different"
4. **Faith-Compliant Path** (Blue Ocean, religious markets) — Shariah-compliant or equivalent · Long-form carousel + Founder · Risk: needs religious-authority validation
5. **Named Couple Case Study** (Proof-Led) — real client transformation with specific income range + outcome · UGC testimonial · Risk: over-reliance on one story
6. **Hidden Equity Reveal** (Unaware → Desire) — show the buyer wealth they didn't realise they have · Static + Carousel · Risk: "too good to be true" flag if not specific
7. **Are You Upgrading for the Right Reasons?** (Contrarian / Counter-Narrative) — slow down the decision · Founder · Risk: may suppress short-term CR
8. **N+ Families In-Group Social Proof** (Proof-Led) — specific number anchored to verifiable transactions · Static + Video · Risk: number must be currently verifiable

## SaaS (B2B + B2C software, recurring subscription)

**Sophistication baseline:** L3-L5 depending on category. CRM/email/analytics are L5; new AI categories L2-L3.
**Awareness baseline:** Solution-Aware → Product-Aware. Buyers comparing 3-5 vendors at decision time.

**Core message recommendation:** Option C (mechanism-led) for L4-L5 categories. Option B (outcome-led) for L2-L3 emerging categories.

**Drafted angle patterns:**
1. **The Hidden N Hours** (Problem-Aware) — quantify time/cost of the manual workflow buyers don't realise they're losing · Static + Carousel · Risk: needs honest math
2. **Migration Without the Migration** (Contrarian) — anti-switching-cost framing, "we make moving from <competitor> the easy part" · Demo video + Carousel · Risk: needs proof of migration ease
3. **Stack Consolidation** (Desire-Led) — replace N tools with 1, surface the cost savings · Comparison carousel + Founder · Risk: comparison must be fair
4. **Feature That Solves the One Thing** (Mechanism) — name the unique mechanism that competitors don't have · Demo video + Static · Risk: feature must be genuinely differentiated, not table-stakes
5. **Free While You Decide** (Offer-Led) — extended free trial / sandbox without credit card · Static + Founder · Risk: trial-to-paid conversion must be tracked tightly
6. **G2 Top-Ranked in <Category>** (Proof-Led) — verifiable third-party rating · Static · Risk: rating must be current
7. **Used by N+ Teams at <Notable Brands>** (Social Proof) — logo bar + specific use case · Carousel · Risk: logos require permission
8. **The N-Day ROI Calculator** (Mechanism / Proof) — interactive tool showing payback period · Static + Carousel · Risk: assumes inputs honestly entered

## Ecommerce (physical product, online checkout)

**Sophistication baseline:** L4-L5 in saturated categories (skincare, supplements, apparel). L2-L3 for niche/new product types.
**Awareness baseline:** Problem-Aware → Solution-Aware. Buyers scrolling discovery, comparing 2-3 brands.

**Core message recommendation:** Option B (outcome-led) for L2-L3 categories. Option C (mechanism-led with ingredient/material specificity) for L4-L5.

**Drafted angle patterns:**
1. **Before/After in N Days** (Proof-Led) — visual transformation with specific timeline · UGC + Static · Risk: must comply with platform claim policies
2. **The Ingredient/Material Most Brands Skip** (Mechanism) — name the differentiator with specificity · Demo + Carousel · Risk: needs to be true
3. **Made For The N% Who <specific buyer>** (Identity / Segment) — niche down hard · UGC + Static · Risk: addressable market may be too narrow
4. **Founder Story** (Contrarian / Authentic) — why the brand was built, what it replaced · Founder video · Risk: founder must be camera-ready
5. **Real Customer N-Star Reviews** (Social Proof) — review screenshots with author name + face · Carousel + Static · Risk: review must be real and disclosed
6. **Stack the Bundle** (Offer-Led) — value framing for AOV expansion · Static + Carousel · Risk: must improve unit economics
7. **Free Shipping / 30-Day Returns** (Trust / Risk-Reversal) — friction removal · Static · Risk: must be operationally true
8. **Limited Stock Drop** (Urgency) — genuine scarcity · Static + UGC · Risk: must not fake scarcity (FTC + platform issue)

## Local / Professional Service (clinics, consultants, trades)

**Sophistication baseline:** L2-L4 depending on category. Hyperlocal services (plumbing, dentistry) are L2-L3 (still mostly outcome-led). Professional services (law, finance) L4-L5.
**Awareness baseline:** Problem-Aware → Solution-Aware. Often urgent intent (toothache, leak, audit deadline).

**Core message recommendation:** Option B (outcome-led + speed) for urgent-intent categories. Option C (mechanism-led) for high-consideration professional services.

**Drafted angle patterns:**
1. **N-Day Relief Promise** (Outcome-Led) — speed of result + outcome anchor · UGC testimonial + Static · Risk: must deliver
2. **Anti-Practice Positioning** (Contrarian) — what other providers do that hurts the patient/client · Founder · Risk: don't name competitors, frame as industry-wide
3. **Same-Day Booking Available** (Trust / Convenience) — friction removal vs typical 2-week wait · Static · Risk: must operationally support
4. **Insurance/Subsidy Accepted** (Proof / Trust) — financial barrier removal · Static · Risk: list must be current
5. **Real Patient Story** (Proof-Led) — named-permission testimonial with face · UGC video · Risk: HIPAA/PDPA compliance
6. **Founder/Owner On Camera** (Trust) — humanise the practice, not corporate · Founder video · Risk: practitioner must be camera-comfortable
7. **N Years Serving <Specific Neighbourhood>** (Social Proof) — hyperlocal credibility · Static · Risk: number must be verifiable
8. **Limited Slots This Month** (Urgency) — real calendar scarcity · Static · Risk: must not manufacture urgency

## Info Product (course, coaching, community, info-as-product)

**Sophistication baseline:** L4-L5 in saturated niches (real-estate, dropshipping, copywriting). L2-L3 in emerging niches.
**Awareness baseline:** Solution-Aware. Buyers have tried free content, are deciding whether to pay.

**Core message recommendation:** Option C (mechanism-led) — buyers have heard every outcome promise. They want the unique HOW.

**Drafted angle patterns:**
1. **The N-Step Method** (Mechanism) — proprietary framework with a name · Founder VSL + Carousel · Risk: must be genuinely novel
2. **Anti-Guru Positioning** (Contrarian) — "what other course-sellers won't tell you" · Founder VSL · Risk: needs specific anti-patterns named
3. **Student Transformation Story** (Proof-Led) — named student with verifiable result + before/after · UGC testimonial + Founder · Risk: results must be typical or disclaimed
4. **From <Bad State> to <Outcome> in N Days** (Outcome) — specific timeline + outcome · Founder VSL · Risk: outcome must be replicable
5. **Cohort Closing in N Days** (Urgency) — real enrolment deadline · Static + Founder · Risk: must not extend artificially
6. **The N Mistakes Most People Make** (Education / Authority) — value-first content that earns the click · Carousel · Risk: must be substantive, not click-bait
7. **Free Webinar / Cheatsheet** (Lead Magnet) — low-friction entry · Static · Risk: lead-to-purchase rate must be tracked
8. **Community of N+ Members** (Social Proof) — peer learning + accountability · Static + UGC · Risk: community must be active, not ghost-town

## Marketing / B2B Agency (done-for-you services to other businesses)

**Sophistication baseline:** L4-L5. Every agency claims "ROI-driven" + "data-backed" + "results-focused". The market is exhausted.
**Awareness baseline:** Solution-Aware → Product-Aware. Prospects have worked with 1-3 agencies before, often burned.

**Core message recommendation:** Option C (mechanism-led) — name the proprietary process. Option A (problem-led) — directly acknowledge prior agency scar tissue.

**Drafted angle patterns:**
1. **The Anti-Agency Agency** (Contrarian) — directly call out what other agencies do wrong · Founder VSL + Static · Risk: needs specific behaviours named, not vague
2. **The N-Step Process** (Mechanism) — proprietary framework with specificity · Carousel + Founder · Risk: must be substantive, not packaged-up commodity work
3. **Performance-Based Pricing** (Offer-Led) — only paid when client wins · Static + Founder · Risk: must structurally support this model
4. **Case Study with Pipeline / Revenue Numbers** (Proof-Led) — specific brand + specific result · Carousel · Risk: must have client permission
5. **Limited Client Roster** (Urgency / Premium) — only N clients per quarter · Static · Risk: must enforce
6. **Founder With Specific Authority** (Trust) — operator background, not "I worked at <agency>" · Founder VSL · Risk: must be camera-ready + credible
7. **Niche Specialisation** (Identity / Segment) — only serve <one specific industry> · Static · Risk: TAM may be limited
8. **Anti-Long-Contract** (Contrarian) — month-to-month, no lock-in · Static · Risk: must accept higher churn

## How to use this file in Phase 4 HITL drafting

1. Read intake JSON → extract `product_type`
2. Load the corresponding section above
3. Use the 8 drafted patterns as scaffolding for Q3 (Priority Angles) options
4. Customise each pattern with research-specific specificity (named numbers, named methodology, named transformation)
5. Rank top 3 with "(Recommended #N)" markers based on sophistication + research findings
6. NEVER paste a generic pattern without customisation — each angle must reference at least one verbatim buyer quote from the dossier OR one specific brand asset

If `product_type` is missing or "Other", surface to user before drafting Phase 4 options. Don't guess.
