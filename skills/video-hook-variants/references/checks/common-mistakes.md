# Common Hook Mistakes

Four ways hooks fail — map directly to the Four Horsemen audit.

## 1. Delay

**What it looks like:** Value is not delivered in the first 1–2 seconds. The hook starts with a warmup phrase, greeting, credentials, or meta-narration before getting to the point.

**Why viewers leave:** The brain is pattern-matching for relevance at ~0.5 seconds. Any signal that says "the value hasn't started yet" triggers scroll.

**Fix:** Start mid-value. The first word should be the topic or the emotion. Cut everything before it.

---

## 2. Confusion

**What it looks like:** Too wordy, too coded, too complicated. The viewer has to consciously decode the sentence instead of absorbing it.

**Test:** If a 12-year-old can't get it instantly → rewrite. No technical terms, no industry jargon, no layered clauses.

**Fix:** Break the sentence. Use simpler words. Shorter lines. One idea per sentence.

---

## 3. Irrelevance

**What it looks like:** Viewer doesn't know why this matters to them. The hook is told from the creator's perspective ("I did X") without anchoring to the viewer's world.

**Fix:** Shift to "you/your" language. Anchor with an avatar-specific tell: a sensation, scenario, or identity marker the target viewer recognizes. Or tag the underlying emotion — even if the specific scenario doesn't apply, the emotion creates the bridge.

---

## 4. Disinterest

**What it looks like:** No curiosity gap, no contrast, no emotional pull. The hook is flat. Static. Expected. The viewer feels nothing in the first 2 seconds.

**Fix:** Inject contrast. Create a Point A → Point B gap. "What people believe" vs "what you're about to show them." The bigger the gap, the stronger the pull to stay.

---

## Quick Diagnosis Table

| Symptom | Likely mistake | Primary fix |
|---|---|---|
| Opens with warmup phrase | Delay | Delete the warmup, start with the topic |
| Viewer doesn't know the topic in 3s | Delay + Confusion | Simplify and front-load the What |
| Feels like it's not for them | Irrelevance | "You/your" + avatar anchor or emotion tag |
| Viewer feels nothing | Disinterest | Add contrast, Point A → Point B |
| Too wordy | Confusion | Break into shorter clauses, simpler words |
| Sounds generic | Disinterest + Irrelevance | Specificity cures both |
