# Verbal / Audio Hook Examples

First words spoken. Active voice. ≤14 words. Hard down-tone endings.

## Operator-Supplied Examples

- "This is 400 slices of bread. This is a breathalyzer. Today we're going to see if you can get drunk off bread."
- "This is how my bosses left their stable jobs to start a cereal company."
- "Why does nobody talk about the cost of staying in the wrong circle?"
- "My mom's business will fail if I don't do something about it."

## Why These Work

| Example | Hook mechanism |
|---|---|
| 400 slices / breathalyzer | Visual carries the hook; verbal is plain but the absurd setup makes it work. Topic clarity instant. |
| Bosses left stable jobs | Sensationalism (reversal — bosses becoming founders) + curiosity gap (how?) |
| Cost of the wrong circle | Relatability (universal fear) + curiosity gap (nobody talks about it = forbidden topic signal) |
| Mom's business will fail | Stakes (family + failure) + implied hero arc |

## Rules (applied to all verbal hooks)

- Active voice. Subject → verb → object.
- ≤14 words where possible. Every word earns its place.
- Hard DOWN-tone on declarative line endings. No upspeak. No question-mark intonation on statements.
- Lead with What + Why (Modern W Order). Never start with Where or When.
- Pass 12-year-old clarity test: no coded language, no jargon, no layered clauses.

## The Three-Step Formula (optional structure)

For hooks that need an internal setup-payoff arc within 5–7 seconds:
1. **Context Lean-In** — state the What + Why bluntly (1 sentence).
2. **Scroll Stop Interjection** — "But," "However," "Yet" (signals revelation coming).
3. **Contrarian Snapback** — the sentence that reverses the lean. Bigger shock = better.

Example: *"Your lab said 'within range.' But within whose range?"* (5 words → contrast → 4 words. Done in 3 seconds.)

Use when the concept's spine is a contrarian frame. Skip when the concept relies on relatability + slow-burn recognition.
