# Three Hook Types

A hook can use one, two, or all three types. Using all three is not required — one type carrying the hook strongly is sufficient if the others stay aligned.

## Visual Hook

**What it is:** What the eye sees in the first frame. Must work with sound off — the scroll-stopper.

**Rules:**
- High motion, high color, or high contrast where possible.
- Must communicate the topic or emotional context before any audio loads.
- Compensates for a merely-okay verbal line. If the visual is absurd or extreme enough, the VO can be plain.

**See examples:** `references/examples/by-type/visual-hooks.md`

---

## Text Hook

**What it is:** On-screen text overlay — 3–5 bold words appearing within 0:00–0:02. NOT subtitles.

**Rules:**
- People read faster than they hear. Text establishes topic context before VO catches up.
- Must be readable in a single glance.
- Pairs with visual to pre-load context.
- Does NOT replace the verbal layer — it reinforces it.

**See examples:** `references/examples/by-type/text-hooks.md`

---

## Verbal / Audio Hook

**What it is:** The first words spoken — VO line or dialogue.

**Rules:**
- Active voice.
- ≤14 words where possible.
- End declarative lines with a hard DOWN-tone. No upspeak. No question-mark endings on statements.
- Must pass the Modern W Order test — lead with What + Why, not Where / When.
- Must pass the 12-year-old test: would a 12-year-old immediately understand the verbal layer?

**See examples:** `references/examples/by-type/verbal-hooks.md`

---

## Combination Rules

| Combination | Use when |
|---|---|
| Visual only | Silent feed, extreme visual speaks for itself |
| Text + Visual | No-dialogue / quiet ads, caption-dominant environments |
| Verbal + Text | Standard talking-head / UGC formats |
| All three | Maximum impact; each layer reinforces the same one idea (Lego Brick Alignment) |

**The Visual-Supplement-Verbal trick:** if the VO line is solid but not viral on its own, compensate with a dominant visual or text layer. One layer carrying the hook well is sufficient if the others stay aligned. Do not force three equally strong layers — that often produces three medium layers and a confused viewer.

**Lego Brick Alignment (HARD):** all three layers used must reinforce ONE idea per variant. Misaligned layers = confusion = churn. See `references/frameworks/lego-bricks.md`.
